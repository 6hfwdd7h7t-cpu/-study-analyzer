# Study Analyzer Web Ver.3.4

## 変更点
- 端末内 Whisper Tiny をUIから撤去（低精度な全文を手修正する運用を廃止）
- 「次にここだけ教えて」方式のアクティブラーニング話者判定
- 自分 / 相手 / 不明 の判定のみで話者モデルを育てる
- 判定候補は、低信頼・長さ・時間的なばらつきを使って自動選択
- 重要区間に ★、一言の要点、会話機能（質問/自己開示/分析・仮説/同意・相槌/修正・反論/話題転換/冗談・雑談）を付与
- ボイスメモ等の全文文字起こしを「参考全文」として貼り付け/TXT読込
- 参考全文は話者・時刻未確定として扱い、一言一句の手修正を前提にしない
- 分析パックでは人間判定を最優先し、自動話者の低信頼値を断定に使わない

## プライバシー
WAV原音は保存・アップロードしません。
解析結果、話者判定、要点メモ、参考全文はブラウザのIndexedDBに保存されます。
完全バックアップJSONを書き出した場合、そのJSONには会話分析内容も含まれます。
