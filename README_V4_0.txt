Study Analyzer Web Ver.4.0

目的:
録音を入れたら、ユーザーが逐語録を確認・修正しなくても、
ChatGPTが会話の内容・流れ・意味を理解できる内部パックを作る。

流れ:
1. WAVを「このiPhoneで解析」
2. できれば自分/相手を各数区間だけ判定
3. 「内部内容解析を開始 / 再開」
4. 完了後「ChatGPTに内部理解パックを共有」
5. 共有シートでChatGPTを選ぶ。出ない場合はJSONを保存して添付

内部内容解析:
- 高精度: Whisper Small
- 標準: Whisper Base
- 26秒区間 / 2秒オーバーラップ
- 逐語録本文は画面非表示
- 途中保存・再開対応
- Smallが使えなければBaseへ自動フォールバック

プライバシー:
- WAVは文字起こしサーバーへ送らない設計
- AIモデル取得時はCDN/Hugging Faceへ通信
- 内部文字起こしは端末内IndexedDBに保存
- ChatGPT共有を押した時だけ、内部全文を含むJSONが端末外へ出る
- JSONには生WAVを含めない
