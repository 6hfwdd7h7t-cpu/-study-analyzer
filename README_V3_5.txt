# Study Analyzer Web Ver.3.5

## 追加
- 「両方」話者：2人同時発話を人間が判定
- 「話者なし」：笑い・物音・非言語のみ等を分離
- 会話機能に 相槌 / 笑い / 同時発話 / 非言語反応 を追加
- タイムライン絞り込みに 同時発話 / 相槌 / 笑い を追加
- ボイスメモ前提の説明を削除
- 全文文字起こしは必須にしない
- 声のない頷き・視線・表情は音声では検出できないため、動画確認時の手動ラベルとして扱う

## 推奨運用
1. 音声を解析
2. 「判定だけで育てる」で 自分 / 相手 / 両方 / 話者なし / 不明 を必要な区間だけ判定
3. 重要区間だけ ★ / 要点 / 会話機能 を付ける
4. 分析パックをChatGPTへ渡す

## 注意
モノラル音声では同時発話の完全分離はできません。
「両方」は人間の原音確認を優先します。
