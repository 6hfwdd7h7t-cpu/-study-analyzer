# プライバシー（v1.1）

- 音声処理はMac/PC上でローカル実行します。
- 選択した音声の作業用コピーと16kHz解析用WAVはOSの一時領域に作られますが、解析終了時に明示的に削除します。
- faster-whisper / pyannote のモデルは初回にネットからダウンロードされることがありますが、解析する音声そのものをHugging Faceへ送る設計ではありません。
- Streamlitの利用統計送信は無効化し、サーバーは127.0.0.1（このMacのみ）に限定しています。
- JSON/TXTには文字起こし内容が含まれます。これらをGitHub、クラウド、ChatGPT等へアップロードすると、その時点で端末外へ出ます。
- 元の音声ファイルは元の保存場所に残ります。アプリが原本を削除することはありません。

# Conversation Audio Analyzer v1

明見との会話のような長時間録音を、**文字内容だけでなく、誰が・いつ・どのくらい・どれだけ間を空けて話したか**まで解析するローカルアプリです。

## v1で出すもの

- ローカルWhisperによる全文文字起こし
- 発言開始・終了時刻
- 話者分離（任意：pyannote）
- 発話時間・発話占有率
- ターン数・平均ターン長
- 応答潜時
- 0.5秒以内などの高速応答率
- 前の話者と重なって開始したターン
- 話者分離上の被せ区間
- 日本語の簡易話速（文字/分）
- 音量（RMS dB）
- F0（声の高さ）の中央値
- ChatGPTへ渡す分析パックTXT

## 大事な考え方

このアプリは「被せが多い＝先読み」「声が低い＝悲しい」のような断定はしません。

1. 測れる事実を数値化する
2. 気になる時刻を絞る
3. 発言内容・原音を確認する
4. ChatGPTで会話機能と心理的意味を仮説化する

という使い方を前提にしています。

# Macでの導入

## 1. Python
Python 3.11 推奨。

```bash
python3 --version
```

## 2. ffmpeg
Homebrewがあれば:

```bash
brew install ffmpeg
```

## 3. Python環境
このフォルダをターミナルで開いて:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

初回はWhisper/PyTorch等のダウンロードがあるので時間がかかります。

## 4. 起動

```bash
source .venv/bin/activate
streamlit run app.py
```

ブラウザが開きます。

# 話者分離を使う場合

無料のHugging Faceアカウントを作り、pyannoteの話者分離モデルの利用条件に同意してtokenを取得します。

アプリ左側の `Hugging Face token` 欄にtokenを入れてください。

tokenなしでも文字起こし・音量・F0は動きますが、**俺 vs 明見、被せ、誰がどれだけ話したか**の分析は弱くなります。

---

# 明見との35分録音の推奨設定

- Whisper: `large-v3`
- 言語: `ja`
- 想定話者数: `2`
- 高速応答しきい値: `500ms`

古いMac・重い場合は `medium` → `small` と下げてください。

# 解析後

話者名が `SPEAKER_00`, `SPEAKER_01` と出るので、画面下で

- SPEAKER_00 → 俺
- SPEAKER_01 → 明見

のように対応させて、`ChatGPT分析パック (TXT)` を保存します。

そのTXTをこのチャットに添付すれば、

- 先読みしすぎの候補
- 相手に余白を残している場面
- 明見→俺→明見の思考介入ループ
- 主導権の移動
- 即答と熟考の違い
- 被せが相槌なのか補完なのか

を、時刻付きで分析できます。

---

# v1の限界

- モノラル録音では同時発話の話者分離に誤りが出ます。
- Whisperは固有名詞・小声・被せで誤認識します。
- F0は環境音や同時発話の影響を受けます。
- 日本語話速は文字/分の簡易値です。
- 「先読み」は直接測定できません。応答潜時・被せ・内容から仮説化します。
- 感情診断・性格診断はしません。

## v2候補

- タイムラインの行をクリック → その原音だけ再生
- 被せ / 0.3秒以内即答 / 長い沈黙をワンクリック抽出
- 話者名対応をもっと簡単にする
- 笑い・フィラー検出
- 相槌と割り込みの分類
- 質問 / 仮説提示 / 同意 / 修正 / 自己開示の会話行為ラベル
- 「相手に余白を残す」指標
- 会話セッション同士の比較
