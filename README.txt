Study Analyzer Web Ver.3.0 — iPhoneローカル会話音響解析

更新内容
- 会話タブからWAVを直接選択してiPhone内で解析
- 音声はサーバーへアップロードしない
- 長いWAVは全体を一度にメモリ展開せず、分割読み込み
- 推定発話率 / 無音時間 / 発話区間候補 / ポーズ分布 / 音量 / F0の目安
- 2秒以上ポーズの抽出
- 解析結果だけIndexedDBへ保存。原音WAVは保存しない
- 原音を再選択すると各区間をその場で再生可能
- PC版JSON読み込みも継続対応

重要な制限
- iPhoneローカル版は自動文字起こしをしません
- 俺/明見などの自動話者分離をしません
- モノラル録音から正確な同時発話/被せを判定しません
- 区間間の無音は「応答潜時」ではなく、同一話者内の間も含みます
- 感情・性格・診断を声だけから判定しません
