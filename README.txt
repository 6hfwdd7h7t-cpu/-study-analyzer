学習・認知パフォーマンス分析 Web Ver.1

■ できること
- スマホ/PCブラウザで学習
- 5択問題を自分で追加
- 反応時間を自動計測
- 回答後に自信度1〜5を記録
- 正答率、反応時間中央値、分野別成績を表示
- 「自信度4〜5で誤答」を要注意問題として表示
- JSONで丸ごとバックアップ/復元
- 学習履歴をCSVで出力
- データは端末のブラウザ内に保存
- HTTPSで公開すればホーム画面追加＋オフライン利用に対応

■ 重要
このZIPをiPhoneの「ファイル」アプリから直接開くだけでは、
ブラウザのセキュリティ制限で保存やPWA機能が安定しません。
「Webサイトとして公開」して使うのがおすすめです。

■ PCで動作確認
このフォルダでターミナルを開き、

Windows:
  py -m http.server 8000

macOS:
  python3 -m http.server 8000

その後ブラウザで
  http://localhost:8000
を開きます。

■ iPhoneで使うおすすめ方法
GitHub Pages / Netlify / Cloudflare Pages などのHTTPS静的ホスティングに
この4ファイルをそのまま置けば動きます。

  index.html
  manifest.webmanifest
  sw.js
  icon.svg

公開URLをSafariで開き、
共有ボタン → 「ホーム画面に追加」
でアプリのように起動できます。

■ 保存場所
localStorageというブラウザ内保存領域を使用しています。
Safariのサイトデータを削除するとデータも消える可能性があるため、
定期的に「問題 → 入出力 → JSON保存」でバックアップしてください。

■ 医療用途について
これは個人の学習傾向を見るためのツールです。
標準化された認知機能検査・医学的診断には使用しないでください。
